# Aditya Portfolio

Standalone TanStack Start portfolio for Aditya Kandwal.

## Run locally

```bash
npm install
npm run dev
```

## Media

All portfolio media is stored locally under `public/media/` so the site does not depend on external asset hosting.

- `public/media/videos/reel-1m.mp4` — Case Study 01
- `public/media/images/adi-bootcamp.png` — Case Study 02
- `public/media/videos/ai-01.mp4` … `ai-09.mp4` — Case Study 03
- `public/media/images/digital-marketing-map.png` — Case Study 04

Video poster frames are stored under `public/media/posters/` for fast visual loading before playback.
